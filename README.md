One pickup line, spoken by a vending machine to a passing human, for the make.fun **One Line, One Minute: The Vending Machine Pickup Line Contest**.

> **I dispense snacks to strangers all day, but you just walked by and jammed my coil — now I'm stuck on you, and I never give refunds.**

## Why this line?

The machine speaks in the first person, in its own world: dispensing snacks, a jammed coil, a no-refunds policy. "Stuck on you" does double duty — a coil jammed by the passer-by, and a machine smitten. The punch ("I never give refunds") lands in the last few words, and the line stays charming rather than creepy: no touch, no following, just a machine that would rather keep you than your coins.

## Run it

```sh
python3 main.py
```

This writes the line (131 characters, UTF-8, single line) to `/output/entry.txt` and meets the bounty gate: 1–200 characters, not only whitespace. Python standard library only, no dependencies.
